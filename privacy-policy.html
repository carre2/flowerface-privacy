플라워페이스 개인정보 처리방침

시행일: 2026년 7월 22일

플라워페이스(이하 "앱")는 이용자의 개인정보를 소중히 다룹니다. 이 방침은 앱이

어떤 정보를, 어떻게, 왜 다루는지를 실제 동작 그대로 설명합니다.

한눈에 보기

  • 얼굴 사진은 저장하지 않습니다. 기기에도, 서버에도, 어디에도 남지 않습니다.
  • 계정이 없습니다. 이름·이메일·전화번호를 받지 않습니다.
  • 저장되는 것은 어떤 꽃이 나왔는지와 날짜, 그리고 사용자가 직접 쓴 메모뿐이며,

전부 이용자 기기 안에만 있습니다.

  • 결과는 재미로 보는 오락입니다. 얼굴로 성격·건강·신원을 알아내지 않습니다.

1. 얼굴 사진의 처리

앱의 핵심 기능은 셀카로 닮은 꽃을 찾는 것입니다. 이 과정에서 얼굴 사진이 쓰입니다.

처리 흐름

1. 기기에서 1차 확인 — 사진에 얼굴이 있는지 이용자 기기에서 먼저 판단합니다.

얼굴이 없으면 이 단계에서 끝나며, 사진은 기기 밖으로 나가지 않습니다.

2. 분석 요청 — 얼굴이 확인되면, 표정 정보를 얻기 위해 사진을 앱의 분석 서버로

전송합니다. 서버는 구글 클라우드 비전(Google Cloud Vision)의 얼굴 검출을

호출해 표정·얼굴 각도 같은 수치만 받아 앱에 돌려줍니다.

3. 즉시 삭제 — 서버는 분석 응답을 돌려준 직후 원본 사진을 메모리에서 지웁니다.

사진은 서버의 디스크에 기록되지 않으며, 어떤 형태로도 영속 저장되지 않습니다.

4. 기기에서 결과 계산 — 어떤 꽃이 나올지는 앱이 이용자 기기에서 계산합니다.

서버는 결과(어떤 꽃인지)를 알지 못합니다.

서버로 전송되는 정보는 다음이 전부입니다:

  • 얼굴 사진 (분석 직후 삭제)
  • 익명 기기 식별자 (아래 3항 참조)
  • 앱 버전

서버가 로그에 남기는 것: 요청 식별번호, 처리 소요 시간, 성공 여부뿐입니다.

얼굴 사진과 표정 수치는 로그에 기록하지 않습니다.

2. 기기에 저장되는 정보

아래 정보는 이용자의 기기 안에만 저장되며, 서버로 전송되지 않습니다.

항목내용
분석 기록배정된 꽃 이름, 분석한 날짜·시각, 즐겨찾기 여부, 이용자가 쓴 메모
도감지금까지 만난 꽃 목록과 수집 시각
생년월일탄생화를 계산하기 위한 값. 선택 입력이며 넣지 않아도 됩니다
앱 설정테마, 소리·진동, 꽃잎 효과

분석 기록에는 얼굴 사진의 경로나 원본이 들어갈 자리 자체가 없습니다.

앱 데이터베이스 구조에 얼굴 사진 항목을 두지 않았기 때문에, 실수로도 저장될 수

없습니다.

이 정보는 앱을 삭제하면 함께 사라집니다. 이용자는 언제든 앱 안에서

직접 삭제할 수 있습니다 (설정 → 데이터 관리, 설정 → 내 정보).

3. 익명 기기 식별자

분석 서버는 기기당 요청 횟수를 제한하기 위해 익명 식별자를 사용합니다.

남용과 과도한 요금 발생을 막기 위한 것입니다.

이 식별자는:

  • 앱을 처음 실행할 때 만들어지는 무작위 값입니다.
  • 계정도, 광고 식별자도, 기기 고유번호도 아닙니다.
  • 이 값만으로는 이용자가 누구인지 알 수 없습니다.
  • 앱을 삭제하면 사라집니다.

4. 개인정보를 제공받는 제3자

앱은 얼굴 검출을 위해 구글 클라우드 비전 API를 이용합니다. 얼굴 사진은

앱의 분석 서버를 거쳐 이 API로 전달되며, 표정 수치를 받은 뒤 즉시 삭제됩니다.

  • 처리 위탁 대상: Google LLC (Google Cloud Vision)
  • 위탁 목적: 얼굴 표정·각도 검출
  • 보관: 하지 않음 (분석 즉시 삭제)

그 외 어떤 제3자에게도 이용자의 정보를 제공하거나 판매하지 않습니다.

광고 네트워크, 분석 도구(트래킹 SDK)를 사용하지 않습니다.

5. 오락 목적 고지

앱의 결과는 재미를 위한 오락 콘텐츠입니다.

  • 얼굴로 성격, 건강, 신원, 감정 상태를 진단하거나 판별하지 않습니다.
  • 표정 정보는 오직 "어울리는 꽃"을 고르는 놀이의 재료로만 쓰입니다.
  • 결과에 과학적·의학적 근거는 없습니다.

6. 이용자의 권리

이용자는 언제든지 다음을 할 수 있습니다.

  • 분석 기록 삭제: 설정 → 데이터 관리 → 전체 기록 삭제
  • 생년월일 삭제: 설정 → 내 정보 → 생년월일 지우기
  • 전체 삭제: 앱을 삭제하면 기기에 저장된 모든 정보가 사라집니다.

앱에는 계정이 없으므로, 별도의 탈퇴 절차나 서버에 남은 개인정보 삭제 요청이

필요하지 않습니다. 서버에는 애초에 이용자를 식별할 수 있는 정보가 저장되지

않습니다.

7. 아동의 개인정보

앱은 만 14세 미만 아동을 주 대상으로 하지 않습니다. 얼굴 사진을 저장하지 않고

계정을 만들지 않으므로, 아동의 개인정보가 수집·보관되지 않습니다.

8. 처리방침의 변경

이 방침이 바뀌면 시행일을 갱신하고 앱 안에서 다시 안내합니다. 얼굴 데이터

처리 방식처럼 중요한 변경이 있을 경우, 이용자에게 다시 동의를 받습니다.
